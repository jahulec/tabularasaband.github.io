# Poppins Black

Source: https://github.com/google/fonts/blob/main/ofl/poppins/Poppins-Black.ttf

Downloaded 2026-10-21 and converted to local WOFF and WOFF2 with fontTools. The original font declares weight 900 (Black). License: OFL-Poppins.txt, SIL Open Font License 1.1.

Poppins-Black-v1.woff2 and Poppins-Black-v1.woff replace the incorrectly named legacy PoppinsBlack files in active styles and preloads. Those legacy files actually contain Regular (400) glyphs.
